# Part ⑥ 画像問題の画像追加 (2026-06-08)

## 概要

Part ⑥ の `hasImage: true` な 51 問すべての画像ファイルを PDF から抽出し、`images/` に保存した。
`questions.json` の `localImagePath` はすでに正しく設定されていたため変更なし。

## 対象ファイル

| 項目 | 詳細 |
|------|------|
| 追加画像数 | 51 ファイル |
| 保存先 | `images/no{N}.png` |
| ソース | `pdf/200-301J.pdf` (PyMuPDF で直接抽出) |
| フォーマット | PNG (localImagePath が `.png` 指定のため) |

## 抽出方法

PDF `200-301J.pdf` の各ページから `fitz` (PyMuPDF) で埋め込み JPEG/PNG オブジェクトを直接抽出し、PNG に変換して保存した。

### ページ配置パターン

PDF の問題は以下の 2 パターンで画像を持つ：

1. **同一ページ埋め込み**: 問題文と選択肢が同一ページにあり、画像も同一ページに埋め込まれている
2. **次ページ埋め込み**: 問題文がページをまたがる場合（ページ末に `IT Certification Guaranteed` で終わる）、選択肢と画像は次のページに配置される

### 特殊ケース

- **Q14 / Q15**: 同一 PDF オブジェクト (xref=3114) を共有 → `no15.png` は `no14.png` のコピー
- **Q338 / Q1165**: 同一 PDF オブジェクト (xref=3267) を共有 → `no1165.png` は `no338.png` のコピー
- **Q369**: ページ 207 に 352×82 の小さなルーティングテーブル画像として埋め込み
- **Q1257**: 問題文はページ 735 だが、画像と選択肢はページ 736 に配置

### `image_questions.json` 未収録の問題

extract_image_questions.py のパースエラーやページまたがりにより除外されていた問題：
Q31, Q74, Q90, Q132, Q338, Q369, Q516, Q1257

これらもページを直接特定して PDF 画像オブジェクトを抽出した。
